# Titanic Exploratory Data Analysis (EDA)

## Objective
Understand the Titanic dataset using statistics and visualizations.

## Analysis Performed
- Dataset exploration
- Summary statistics
- Histogram analysis
- Boxplot analysis
- Correlation matrix
- Pairplot
- Survival pattern analysis

## Key Findings
- Most passengers were aged between 20 and 40.
- Female passengers had a higher survival rate.
- First-class passengers survived more often.
- Fare shows a relationship with survival.
- Outliers exist in Age and Fare columns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

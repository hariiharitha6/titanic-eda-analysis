# Titanic Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic dataset to understand the data through descriptive statistics and visualizations, identify patterns, trends, relationships, and gain insights that can help in machine learning model development.

## Dataset

* Dataset: Titanic Dataset
* Type: Classification Dataset
* Records: 891 Passengers
* Features: Passenger details such as Age, Sex, Fare, Passenger Class, Embarkation Point, and Survival Status.

## Tools and Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Analysis Performed

1. Loaded and explored the dataset.
2. Examined dataset structure, dimensions, and data types.
3. Generated summary statistics using descriptive analysis.
4. Created histograms to study feature distributions.
5. Created boxplots to identify outliers.
6. Generated a correlation matrix to understand relationships between numerical features.
7. Created pairplots for feature comparison and pattern recognition.
8. Analyzed survival patterns based on passenger attributes.

## Visualizations Generated

* Age Distribution Histogram
* Age Boxplot
* Fare Boxplot
* Correlation Heatmap
* Pairplot of Important Features

## Key Findings

* Most passengers were between 20 and 40 years of age.
* Female passengers had a significantly higher survival rate than male passengers.
* First-class passengers had better survival chances compared to lower classes.
* Fare showed a positive relationship with passenger survival.
* Outliers were present in Age and Fare features.
* Certain numerical features exhibited weak to moderate correlations.

## Conclusion

Exploratory Data Analysis helped in understanding the structure and characteristics of the Titanic dataset. Through statistical summaries and visualizations, important patterns, relationships, and anomalies were identified, providing valuable insights for future machine learning tasks.
